# Sistema POS Minimarket

## Objetivo

Desarrollar un sistema POS que permita administrar ventas, inventario y compras
de un minimarket de forma rápida, confiable y sencilla.

## Problema actual

Actualmente el negocio registra las ventas manualmente o con herramientas
básicas, lo que genera problemas como:

- falta de control del inventario
- dificultad para conocer las ganancias reales
- errores humanos al registrar ventas
- dificultad para saber qué productos se venden más
- pérdidas por productos vencidos

## Solución propuesta

El sistema POS permitirá:

- registrar ventas rápidamente desde una interfaz simple
- controlar el inventario por lotes y fechas de vencimiento
- registrar compras a proveedores
- generar reportes de ventas
- mejorar el control del negocio

## Alcance inicial (MVP)

La primera versión incluirá:

- gestión de productos
- gestión de categorías
- registro de ventas
- control de inventario por lotes
- registro de compras
- gestión de proveedores
- control de usuarios (admin / cajero)
